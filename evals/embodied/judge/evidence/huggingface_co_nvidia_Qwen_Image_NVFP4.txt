# Model Overview

## Description:

The NVIDIA Qwen-Image-NVFP4 model is the quantized version of Qwen's Qwen-Image model, which is a text-to-image diffusion transformer with strong image-generation quality, complex text rendering, and prompt adherence. For more information, please check [here](https://huggingface.co/Qwen/Qwen-Image). The NVIDIA Qwen-Image-NVFP4 model is quantized with [Model Optimizer](https://github.com/NVIDIA/Model-Optimizer).

This model is ready for commercial or non-commercial use.

## Model Architecture:
**Architecture Type:** Diffusion Transformer (MMDiT) <br>
**Network Architecture:** `QwenImageTransformer2DModel` in a `QwenImagePipeline` <br>
**This model was developed based on:** [Qwen/Qwen-Image](https://huggingface.co/Qwen/Qwen-Image) <br>
**Number of Model Parameters:** 20.43B parameters in the denoising transformer; 28.85B learned parameters in the full pipeline when the text encoder and VAE are included. <br>

The full pipeline contains a Qwen2.5-VL text encoder, Qwen tokenizer, 60-layer Qwen-Image transformer, Qwen-Image VAE, and FlowMatch Euler scheduler. The quantized release preserves the base-model architecture while reducing inference precision for supported operators.

**Input Type(s):** Text <br>
**Input Format(s):** String <br>

**Other Properties Related to Input:** The pipeline allows at most 1,024 prompt tokens and defaults to 512. The upstream model card documents support for both English and Chinese prompt workflows. <br>

## Post Training Quantization
This checkpoint stores 784 transformer linear weight matrices in ModelOpt NVFP4 format across blocks 2–57, with 14 quantized matrices per block. Supported inference kernels use NVFP4 weights and activations for these linear operations. Other transformer parameters, the text encoder, and the VAE retain higher precision.

## Usage

This checkpoint was validated with TensorRT-LLM VisualGen 1.3.0rc28 on an NVIDIA GB300 GPU. VisualGen loads the stored ModelOpt NVFP4 weights and quantization configuration directly; no weight conversion or runtime source patch is required.

### 1. Download the checkpoint

Download the complete repository, including the transformer, text encoder, tokenizer, VAE, and scheduler.

```bash
python3 -m pip install --upgrade huggingface_hub

hf download nvidia/Qwen-Image-NVFP4 \
  --local-dir ./Qwen-Image-NVFP4

export MODEL_DIR="$(realpath ./Qwen-Image-NVFP4)"
```

### 2. Create the serving configuration

```bash
cat > visualgen-eager.yaml <<'YAML'
attention_config:
  backend: VANILLA
parallel_config:
  cfg_size: 1
  ulysses_size: 1
torch_compile_config:
  enable: false
cuda_graph_config:
  enable: false
compilation_config:
  skip_warmup: true
YAML

export VISUALGEN_CONFIG="$(realpath visualgen-eager.yaml)"
```

### 3. Start the server

```bash
docker run --rm \
  --gpus '"device=0"' \
  --ipc=host \
  -p 127.0.0.1:8000:8000 \
  -v "$MODEL_DIR:/model:ro" \
  -v "$VISUALGEN_CONFIG:/visualgen-eager.yaml:ro" \
  nvcr.io/nvidia/tensorrt-llm/release:1.3.0rc28 \
  trtllm-serve /model \
    --host 0.0.0.0 \
    --port 8000 \
    --visual_gen_args /visualgen-eager.yaml
```

After the server finishes loading, check its health from another terminal:

```bash
curl --fail http://127.0.0.1:8000/health
```

### 4. Generate an image

```python
import base64
import json
import urllib.request
from pathlib import Path

payload = {
    "model": "/model",
    "prompt": (
        "A realistic photograph of a red ceramic teapot on a wooden "
        "table beside a window, soft morning light, detailed wood grain."
    ),
    "negative_prompt": " ",
    "size": "512x512",
    "num_inference_steps": 50,
    "guidance_scale": 4.0,
    "seed": 42,
    "response_format": "b64_json",
    "format": "png",
}

request = urllib.request.Request(
    "http://127.0.0.1:8000/v1/images/generations",
    data=json.dumps(payload).encode("utf-8"),
    headers={"Content-Type": "application/json"},
    method="POST",
)

with urllib.request.urlopen(request, timeout=600) as response:
    result = json.load(response)

output = Path("qwen-image-nvfp4.png")
output.write_bytes(base64.b64decode(result["data"][0]["b64_json"]))
print(f"Saved {output.resolve()}")
```

## Evaluation

The accuracy benchmark results are presented in the table below:

| Model | Qwen-Image-Bench | OneIG-EN |
| --- | ---: | ---: |
| Baseline (BF16) | 48.986 | 51.337 |
| NVFP4 | 49.754 | 51.563 |

> Baseline: [Qwen/Qwen-Image](https://huggingface.co/Qwen/Qwen-Image), revision `75e0b4be`.
> Qwen-Image-Bench: 1,000 prompts, seed 42.
> OneIG-EN: 1,119/1,120 prompts, seeds 42–45; one prompt excluded before generation.
> Both used 1024×1024, 50 steps, CFG 4.0, and a single-space negative prompt.
> OneIG is the equal arithmetic mean of alignment, text, reasoning, style, and diversity.

## Model Limitations:
The base model may generate inaccurate, low-quality, or otherwise undesirable images, even when prompts are benign. Output quality can vary with prompt language, prompt complexity, and image resolution. The model may also inherit biases or content artifacts from the upstream model and its training data. This checkpoint is not intended for image-understanding tasks, safety-critical applications, or illegal or abusive content generation without additional safeguards and testing.
